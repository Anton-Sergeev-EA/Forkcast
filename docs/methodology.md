# Методика Forkcast

Документ описывает постановку задачи, выбор модели, оценивание, построение сценарного прогноза, оценку
неопределённости и проверку качества. Обозначения: t — квартал, q(t) — номер квартала в году,
M — продажи рынка (шт.), s — доля электропогрузчиков, w — доля сегмента внутри блока.

## 1. Постановка

Нужно прогнозировать 14 рядов (8 сегментов ДВС, 6 электро), их итоги по блокам и рынку на 4 и 8 кварталов
вперёд, с учётом внешних факторов, в нескольких сценариях и с оценкой неопределённости. Особенности данных:

- **13 наблюдений** на ряд — меньше, чем требуется классическим моделям с сезонностью (SARIMA, ETS с сезонной
  компонентой, Prophet) для устойчивой оценки;
- **иерархия**: сегменты → блок → рынок; прогнозы должны суммироваться;
- **разная природа динамики**: циклическое сжатие рынка (ставка, инвестиции) и структурное замещение ДВС
  электрическими (тренд доли);
- **малые разреженные ряды** (десятки штук, округление до 10).

Отсюда архитектура «сверху вниз»: факторы объясняют уровень рынка, отдельная модель — долю электро,
композиционная модель — структуру внутри блоков. Каждый уровень оценивается на агрегатах с максимальным
отношением сигнал/шум.

## 2. Признаки

**Эффективная ключевая ставка**: `R^eff_t = (R_{t-1} + R_{t-2} + R_{t-3}) / 3`, где R — средняя за квартал
(по дням) ключевая ставка. Лаг отражает трансмиссию денежно-кредитной политики: решение о закупке → одобрение
кредита/лизинга → поставка. Скрининг корреляций показал максимум связи при лагах 2–3 (r ≈ −0,76…−0,78),
при нулевом лаге связь слабая (r ≈ −0,40). Использование среднего за три лага вместо одного «лучшего»
снижает риск подгонки под выборку.

**Индекс уровня инвестиций**: `I_t = I_{t-4} · (1 + g_t/100)`, где g — темп роста инвестиций в основной
капитал г/г, `I_{2022Qk} = 1`. Индекс не содержит сезонности (сравнение с тем же кварталом) и измеряет
*уровень* инвестактивности, что согласуется с моделью уровня продаж.

**Структурный сдвиг** `S_t = 1{t ≥ 2025Q2}`. Со 2 кв. 2025 г. рынок (особенно ДВС) опустился на уровень,
не объяснимый ставкой и инвестициями: завершился цикл замещения парка после ухода западных брендов
(2023–2024 гг.), вырос утилизационный сбор на самоходную технику (10.2024, 01.2025, 01.2026), ужесточились
неценовые условия банковского кредитования. Переменная включена с нейтральным априори N(0; 0,25):
её величину определяют данные. Включение снижает ошибку LOO с 0,188 до 0,143 и смещение бэктеста.

## 3. Модели

### 3.1. Рынок

```
log M_t = α + γ₂D₂ + γ₃D₃ + γ₄D₄ + β_r·R^eff_t + β_i·log I_t + β_s·S_t + ε_t,   ε_t ~ N(0, σ²)
```

Априорные распределения (независимые нормальные; `config/settings.yaml`):

| Параметр | Априори | Обоснование |
|---|---|---|
| β_r | N(−0,025; 0,02) | полуэластичность спроса на инвестиционное оборудование к ставке: отрицательная, порядка процентов на п.п. |
| β_i | N(1,5; 1,0) | спрос на оборудование реагирует на инвестиции сильнее единицы (акселератор), но широкая неопределённость |
| β_s | N(0; 0,25) | нейтральное — знак и величину определяют данные |
| γ_q | N(0; 0,3) | слабая регуляризация сезонности |
| α | N(ȳ − …; 3) | фактически неинформативное |
| σ² | InvGamma(2; 0,02) | слабоинформативное, мода σ ≈ 0,1 |

### 3.2. Доля электропогрузчиков

```
logit(s_t / cap) = a + c₂D₂ + c₃D₃ + c₄D₄ + b·t + δ·R^eff_t + κ·S_t + u_t
```

Линейный тренд в логит-пространстве — это логистическая S-кривая диффузии технологии с насыщением на
уровне `cap` = 85% (по умолчанию; для сравнения — в Западной Европе электрические машины занимают
большую часть продаж противовесных погрузчиков). Чувствительность к cap ∈ [0,80; 1,00] приведена в отчёте:
через 8 кварталов доля 76–86%. Коэффициент δ проверяет гипотезу о большей чувствительности ДВС к ставке.

### 3.3. Структура сегментов

Для блока с J сегментами доли `w_{jt}` переводятся в аддитивные лог-отношения к крупнейшему сегменту
`z_{jt} = log(w_{jt}/w_{ref,t})` (с псевдосчётом 5 шт. — половина шага округления, чтобы нули не давали −∞).
Уровень — экспоненциально взвешенное среднее (период полураспада 3 кв.), тренд — МНК-наклон, затухающий
с коэффициентом φ = 0,8 за квартал. Неопределённость: ошибка уровня, ошибка наклона и квартальный шум
(стандартные отклонения остатков). Обратное преобразование softmax гарантирует `Σ w = 1`.

### 3.4. Оценивание

Сэмплер Гиббса для полусопряжённой схемы: чередуются точные условные распределения
`β | σ², y ~ N(V(X'y/σ² + V₀⁻¹m₀), V)`, `V = (X'X/σ² + V₀⁻¹)⁻¹` и
`σ² | β, y ~ InvGamma(a₀ + n/2, b₀ + ½‖y − Xβ‖²)`. 6000 итераций, 1000 — прогрев. Воспроизводимость
обеспечивается фиксированным seed.

## 4. Прогноз и неопределённость

Для каждого сценария и каждой из N = 4000 симуляций:

1. **Путь факторов.** Сценарные значения ставки и инвестиций + отклонения
   `e_h = z₀·base + Σ_{k≤h} z_k·step` (случайное блуждание, ограниченное ±max), только для кварталов,
   по которым нет факта. Уже известные значения берутся из данных (наукаст).
2. **Признаки** R^eff и log I пересчитываются по смоделированному пути (с учётом лагов и цепного индекса).
3. **Параметры** берутся из апостериорной выборки; добавляется шум модели σ·N(0,1).
4. **Иерархия**: M = exp(log M), s = cap·logistic(·), ДВС = M(1−s), электро = Ms, сегменты = блок × w.

**Взвешенный прогноз** — смесь сценариев: из каждого сценария берётся доля симуляций, равная его весу.
Квантили смеси учитывают межсценарную неопределённость.

**Бюджет неопределённости** — последовательное включение источников (только параметры → + шум → + путь факторов)
и доля прироста дисперсии log M, приходящаяся на каждый источник.

## 5. Проверка

**Отбор факторов** — точная LOO-ошибка МНК (через диагональ hat-матрицы) для 11 спецификаций:
без факторов, ставка с разными лагами, инвестиции, их комбинации, реальная ставка, курс, ВВП, режим.

**Бэктест** — rolling origin: обучение на первых T кварталах (T = 8…12), прогноз на 1–4 квартала, сравнение с
фактом. Эталоны: сезонный наивный (SNaive), ETS с затухающим трендом по сезонно скорректированному ряду,
сезонное среднее. Метрики: MAPE, MASE (масштаб — MAE сезонного наивного прогноза на всей выборке), смещение,
покрытие 80% и 95% интервалов. Бэктест условный: используются фактические значения факторов.

**Чувствительность**: ширина всех априорных распределений ×0,5 / ×1 / ×2 / ×5; потолок доли электро.

**Мониторинг в эксплуатации**: каждый прогноз сохраняется (винтаж). При поступлении факта считается PIT —
перцентиль факта в прогнозном распределении. Для откалиброванной модели PIT равномерен на [0; 1]; систематический
сдвиг к краям — сигнал перекалибровки или пересмотра сценариев.

## 6. Планирование

Спрос на продукцию СИЛАНТ в сегменте = рынок сегмента × целевая доля. Оптимальный объём выпуска при
асимметричных линейных потерях — квантиль уровня `q* = Cu/(Cu + Co)` прогнозного распределения спроса
(задача газетчика). Cu — упущенная маржа с единицы при дефиците, Co — затраты на хранение и омертвление
капитала единицы при излишке. Параметры и целевые доли — в `config/segments.yaml`.
