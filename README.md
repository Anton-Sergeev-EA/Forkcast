# Forkcast — прогноз рынка вилочных погрузчиков РФ по сегментам

**Forkcast** (*fork* + *forecast*) — воспроизводимый инструмент анализа и сценарного прогнозирования рынка
вилочных погрузчиков России для производственного и продуктового планирования ЧЗСА (бренд **СИЛАНТ**).

Инструмент строит прогноз по 14 сегментам (8 ДВС + 6 электро), по блокам и по рынку в целом на **4 квартала**
(краткосрочный горизонт) и **8 кварталов** (долгосрочный), в пяти сценариях внешних факторов
(Банк России, Минэкономразвития, консенсус аналитиков, стресс, оптимистичный), с оценкой неопределённости,
прогнозом доли электропогрузчиков и переводом результата в коридор производственного плана.
Прогноз пересчитывается одной командой при поступлении данных за новый квартал.

**Неочевидные возможности:**

- **Наукаст.** Уже известные значения факторов (ставка за 3 кв. 2026 г., инвестиции за 2 кв. 2026 г.) подставляются
  вместо сценарных — прогноз ближайших кварталов опирается на факт, а не на допущения.
- **Согласованная иерархия.** Сегменты суммируются в блоки, блоки — в рынок в *каждой* симуляции (а не только в среднем).
- **Бюджет неопределённости.** Дисперсия прогноза раскладывается на параметры модели, случайный шум и путь факторов.
- **«Лестница ставок».** Рынок 2027 г. при ключевой ставке 8–16%: при какой ставке рынок возвращается к уровню 2025 г.
- **Коридор плана и newsvendor.** Перевод вероятностного прогноза в рекомендуемый объём выпуска по сегментам СИЛАНТ
  с учётом асимметрии потерь от дефицита и затоваривания.
- **Винтажи прогнозов.** Каждый прогноз архивируется; при поступлении факта автоматически считаются ошибка, попадание
  в интервалы и PIT — мониторинг калибровки модели.
- **Автообновление ставки и курса** из официальных сервисов Банка России.
- **Устойчивый парсер Excel.** Новые кварталы и сегменты распознаются без правки кода; проверки качества данных.
- **Манифест воспроизводимости.** Версии библиотек, seed и SHA-256 всех входных файлов — в `reports/run_manifest.json`.

## 3. Быстрый старт

Требования: Python 3.10–3.12, ~300 МБ на зависимости. Интернет нужен только для установки пакетов
и (опционально) для `fetch-macro`.

```bash
cd forkcast            # корень проекта
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e . --no-deps

forkcast run                       # полный расчёт (~30 с) и все отчёты
pytest -q                          # 24 автотеста
```

Или через `make`: `make install && make run && make test`.
Или в Docker: `docker build -t forkcast . && docker run --rm -v "$PWD/reports:/app/reports" forkcast run`.

После `forkcast run` в консоли выводится сводка, а файлы обновляются:

```
reports/forkcast_report.html        аналитический отчёт (открывается в браузере, работает офлайн)
reports/forkcast_dashboard.html     интерактивный дашборд (выбор любого из 18 рядов)
reports/forkcast_forecast.xlsx      26 листов: прогнозы, план, сценарии, коэффициенты, бэктест, датасет, источники
reports/forkcast_presentation.pptx  презентация (и .pdf, если установлен LibreOffice)
reports/figures/*.png               графики
data/processed/*.csv                подготовленный датасет
forecasts/vintages/vintage_*.csv    архив прогнозов
```

## 4. Команды

| Команда | Назначение |
|---|---|
| `forkcast run [--quick] [--no-reports] [--market FILE]` | полный расчёт; `--quick` — быстрый режим для проверки |
| `forkcast validate --market FILE` | проверка файла рынка (структура, пропуски, дубликаты, итоги) |
| `forkcast update --market FILE [--fetch]` | принять файл с новым кварталом, пересчитать, оценить прошлые прогнозы |
| `forkcast fetch-macro` | обновить ключевую ставку и курс USD/RUB с cbr.ru |
| `forkcast backtest` | ретроспективная проверка модели и сравнение с эталонами |

Без установки пакета: `PYTHONPATH=src python -m forkcast run`.

## 6. Методика

Подробно — в [`docs/methodology.md`](docs/methodology.md). Кратко:

**Иерархическая байесовская факторная модель** из трёх уровней, согласованных по построению.

1. **Рынок в целом** — динамическая регрессия логарифма продаж:
   `log Mₜ = α + Σ γ_q·D_q + β_r·R^eff_t + β_i·log Iₜ + β_s·Sₜ + εₜ`,
   где `R^eff` — эффективная ключевая ставка (среднее за 1–3 предыдущих квартала), `I` — индекс уровня инвестиций
   в основной капитал, `S` — структурный сдвиг со 2 кв. 2025 г., `D_q` — сезонные дамми.
2. **Доля электропогрузчиков** — логистическая S-кривая с потолком насыщения 85%:
   `logit(sₜ/cap) = a + Σ c_q·D_q + b·t + δ·R^eff_t + κ·Sₜ + uₜ`.
3. **Структура сегментов** внутри блоков ДВС и электро — композиционная модель в аддитивных лог-отношениях
   с экспоненциальным сглаживанием уровня и затухающим трендом.

Итог: `сегмент = M · (доля блока) · (доля сегмента в блоке)` — суммы всегда сходятся.

**Почему так.** 13 наблюдений — слишком мало для классических моделей временных рядов (ARIMA/ETS с сезонностью
требуют 3–5 лет) и для МНК с несколькими факторами. Байесовские слабоинформативные априорные распределения
с экономически обоснованными знаками стабилизируют оценки, а апостериорные выборки (сэмплер Гиббса) дают честную
неопределённость параметров. Факторы отобраны не подгонкой, а по ошибке кросс-валидации «исключи одну точку» (LOO)
среди 11 спецификаций; устойчивость к выбору априори проверена (оценки и прогноз меняются умеренно при
изменении ширины априори в 0,5–5 раз).

**Оценённое влияние факторов** (апостериорные средние, 90%-интервалы):

| Фактор | Эффект |
|---|---|
| Эффективная ключевая ставка | −2,1% продаж на +1 п.п. (−3,9%…−0,4%) |
| Уровень инвестиций в ОК | эластичность ≈ 1,0 |
| Структурный сдвиг 2025Q2 | −19% к уровню рынка |
| Тренд электрификации | +0,09 логита доли за квартал (P>0 = 99,8%) |
| Сезонность рынка | 1 кв. −21%, 4 кв. +16% к среднегодовому (F-тест p = 0,005) |

Пять сценариев в [`config/scenarios.yaml`](config/scenarios.yaml): для каждого — квартальные пути ключевой ставки,
инвестиций, курса и ВВП, текстовое описание допущений, вес и цвет.

| Сценарий | Вес | Ключевые допущения |
|---|---|---|
| Консенсус аналитиков (макроопрос ЦБ, сент. 2026) | 35% | ставка 14,5% / 12,4% / 10,0% в 2026–2028 гг.; ВВП 0,5 / 1,2 / 1,7% |
| Банк России, базовый (СПП июль 2026) | 25% | ставка 14,5–14,6% в 2026 г., 10,5–12,5% в 2027 г.; ВВП 0–1% / 1,5–2,5% |
| Минэкономразвития, базовый (май 2026) | 10% | ВВП 0,4 / 1,4 / 1,9%; инвестиции −1,5% / +2,0% |
| Стресс: жёсткая ДКП и инвестиционный спад | 20% | ставка 14% до 2 кв. 2027 г.; инвестиции падают до конца 2027 г. |
| Оптимистичный: быстрое смягчение ДКП | 10% | ставка 8–10% в 2027 г.; рост инвестиций 4–5% |

Внутри сценария путь факторов тоже неопределён (случайное блуждание с растущей дисперсией, параметры
`factor_uncertainty`). **Взвешенный прогноз** — смесь сценариев с указанными весами: он учитывает и неопределённость
внутри сценариев, и неопределённость выбора сценария.

Чтобы добавить сценарий, скопируйте блок в YAML и задайте значения — код менять не нужно.

## 8. Оценка неопределённости и проверка качества

- **Источники неопределённости** моделируются явно: параметры (апостериорные выборки), шум модели, путь внешних
  факторов, выбор сценария. 4000 симуляций на сценарий.
- **Интервалы** 50/80/95% для каждого ряда и квартала; квантили P2.5…P97.5 — в Excel и `forecast_quantiles.csv`.
- **Бэктест** (rolling origin, точки отсечения 2024Q4–2025Q4, горизонт 1–4 кв., условный по факторам):

| Ряд | Forkcast MASE | SNaive | ETS | Покрытие 80% |
|---|---|---|---|---|
| Рынок | **0,50** | 1,41 | 1,03 | 100% |
| ДВС | **0,60** | 1,47 | 0,91 | 71% |
| Электро | **0,29** | 0,92 | 0,94 | 100% |
| Доля электро | **0,66** | 1,19 | — | 71% |

- **Чувствительность**: к ширине априорных распределений (×0,5…×5) и к потолку доли электро (80…100%).

## 9. Планирование производства

Модуль `planning.py` переводит прогноз в язык производственного плана для сегментов линейки СИЛАНТ (1–5 т):

- **коридор рынка** P10/P50/P90 по кварталам и за горизонт;
- **спрос СИЛАНТ** = рынок × целевая доля (задаётся в `config/segments.yaml`, по умолчанию условные 5%);
- **рекомендуемый выпуск по правилу newsvendor**: квантиль `Cu/(Cu+Co)` распределения спроса, где `Cu` — потери
  от недопроизводства (упущенная маржа), `Co` — потери от перепроизводства (склад, оборотный капитал).
  При значениях по умолчанию квантиль ≈ 71%.

Результат — листы «План_СИЛАНТ_4кв» и «План_СИЛАНТ_8кв» в Excel.

## 10. Обновление прогноза

**Новый квартал рыночных данных:**

```bash
forkcast update --market /путь/к/файлу_с_новым_кварталом.xlsx --fetch
```

Команда проверит файл, скопирует его в `data/raw/` под стандартным именем, обновит путь в `config/settings.yaml`,
загрузит свежие ставку и курс, пересчитает все прогнозы и отчёты, сохранит новый винтаж и выведет точность
прошлых прогнозов по вновь поступившему факту.

**Новые макроданные Росстата** (раз в квартал): добавьте строку в `data/external/macro_quarterly.csv`
(`period, gdp_yoy, investment_yoy, cpi_yoy_eop`) и отметьте источник в `sources.yaml`.

**Новые прогнозы ЦБ / Минэка:** обновите пути факторов и веса в `config/scenarios.yaml`.
Если горизонт прогноза ушёл дальше заданных в YAML периодов, значения продлеваются последним известным
(с предупреждением в логе).

Рекомендуемый регламент: ежеквартально после получения данных рынка; внепланово — после заседаний Банка России,
если ставка отклонилась от сценария более чем на 1 п.п.

## 12. Воспроизводимость и тесты

- фиксированный `seed` в `config/settings.yaml` — повторный запуск даёт те же числа;
- `reports/run_manifest.json`: версии Python/NumPy/pandas, seed, число симуляций, SHA-256 файла рынка и всех
  внешних файлов, веса сценариев;
- `pytest -q` — 24 теста: парсинг (включая автоопределение нового квартала), восстановление коэффициентов
  на синтетике, согласованность иерархии в каждой симуляции, воспроизводимость, экономические знаки, монотонность
  по ставке, превосходство над наивным прогнозом, сквозной прогон конвейера;
- CI (GitHub Actions) — тесты на Python 3.10 и 3.12.

## 13. Ограничения

- **Короткая история (13 кварталов).** Эластичности стабилизированы априорными распределениями; интервалы намеренно
  широкие — это честная мера неопределённости.
- **Нет цен, брендов, регионов и каналов продаж** — нельзя оценить ценовую эластичность, конкуренцию, долю импорта.
  Целевая доля СИЛАНТ задаётся экспертно.
- **8 сегментов ДВС вместо 9**, указанных в описании кейса; прогноз построен по фактической структуре файла.
- **Округление до 10 шт.**: малые сегменты (6–25 т ДВС, 5,5–16 т электро) шумные и прогнозируются через структуру блока.
- **Структурный сдвиг 2025Q2** — событийная переменная; разделить его причины (конец цикла замещения парка после ухода
  западных брендов, утильсбор, неценовые условия кредитования) на имеющихся данных нельзя.
- **Бэктест условный** (фактические значения факторов): архивных прогнозов факторов «на дату» в открытом доступе нет.
- **Часть квартальных макроданных** — из вторичных источников со ссылкой на Росстат (статусы в `sources.yaml`);
  подлежат сверке при ревизиях.
- **Нет открытых квартальных рядов** ввода складов, лизинга спецтехники и импорта погрузчиков.

## 14. Развитие

1. Подключить ряды ввода складской недвижимости, лизинга спецтехники, импорта погрузчиков (таможенная статистика КНР).
2. Добавить данные продаж СИЛАНТ по сегментам — перейти от прогноза рынка к прогнозу продаж и доли бренда.
3. Ввести цены и оценить ценовую эластичность по классам грузоподъёмности.
4. Автоматизировать загрузку квартальных данных Росстата.
5. По мере накопления истории (≥ 20 кварталов) добавить в ансамбль модели с динамической сезонностью.
